QUOTE FOLLOW UP — comece por aqui (Windows)
============================================

COMO A PASTA ESTA ORGANIZADA

  quote-follow-up\
    build.bat              -> DOIS CLIQUES: compila a pagina (rode depois de qualquer mudanca)
    iniciar-servidor.bat   -> DOIS CLIQUES: liga o servidor (depois: http://localhost:8080)
    importar-banco.bat     -> (opcional) planilhas da versao anterior -> banco\import.sql
                              (mais facil: Admin -> aba Dados -> Importar da versao anterior)
    LEIA-ME.txt            -> este arquivo
    README.md              -> manual completo do programa
    package.json, package-lock.json, .gitignore -> nao precisa mexer

    pagina\                -> O PROGRAMA PRONTO
      QuoteFollowUp.html   -> gerado pelo build.bat (nao edite; sem servidor, abra no Chrome/Edge)
      icones\              -> icones do "Adicionar a tela inicial" no celular

    codigo\                -> O CODIGO-FONTE (e aqui que se edita)
      app.jsx              -> a interface: telas, tabelas, calendario
      core.js              -> as regras: relatorios, calculos, agenda de FUP, meta, prioridade
      dcs.js               -> o formulario DCS / Value Added
      logo.jsx             -> o logo da Martin (cores do tema: bloco "const X = {" no app.jsx)
      i18n.js, i18n-pt.js  -> idioma e as traducoes para o portugues
      entry.jsx, styles.css, build.js -> nao precisa mexer
      modelos\                       -> dcs-va-template.pdf (formulario oficial, vazio) e martin-logo.svg

    servidor\              -> O SERVIDOR
      server.mjs                 -> entrega a pagina, faz o login e grava no banco
      server.config.example.json -> modelo da configuracao
      server.config.json         -> a SUA configuracao, com a senha do banco (o iniciar-servidor.bat cria)
      legacy-import.mjs, import-xlsx.mjs -> importacao das planilhas da versao anterior

    banco\                 -> O BANCO DE DADOS (MariaDB)
      schema.sql                   -> cria / atualiza o banco:  mariadb -u root -p < banco\schema.sql
      banco-de-dados-MER-DER.html  -> o desenho do banco (abra no navegador)

    docs\
      SERVIDOR.md          -> instalar o servidor, o tunel e como atualizar
      BANCO-DE-DADOS.md    -> o banco e a importacao das planilhas

  Nunca mande para o GitHub nem por e-mail: servidor\server.config.json (senha do banco),
  banco\import.sql e as planilhas .xlsx (dados da empresa). O .gitignore ja deixa eles de fora.

PASSO 1 — Instalar o Node.js (so na primeira vez)
  - Entre em  https://nodejs.org
  - Baixe a versao "LTS" e instale (Next, Next, Finish).

PASSO 2 — Compilar
  - De dois cliques em  build.bat
  - Na primeira vez ele instala as bibliotecas (demora 1-2 min).
  - No final aparece "Tudo certo!" e o programa fica em pagina\QuoteFollowUp.html

PASSO 3 — Ligar o servidor
  - De dois cliques em  iniciar-servidor.bat  (veja docs\SERVIDOR.md para o tunel e o modo servico).

EDITANDO
  - Abra o codigo\app.jsx num editor (recomendo o VS Code, gratis).
  - Procure pelos comentarios com "====" para achar cada parte.
  - Faca suas mudancas, salve, e rode o build.bat de novo.
  - Mudou o codigo\core.js ou algo na pasta servidor? Reinicie o servidor tambem.

SE DER ERRO
  - O build.bat mostra a linha do erro. Geralmente e uma chave { } ou
    parentese ( ) que ficou aberto. Desfaca a ultima mudanca e tente de novo.
